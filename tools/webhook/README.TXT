To update the Bus Pirate firmware:

Via Terminal:
    Type $ in the Bus Pirate terminal, then press Enter.
    The Bus Pirate will display the firmware file name to load, such as bus_pirate5_rev10.uf2 or bus_pirate6_rev2.uf2.
    
Manually:
    Use a small tool to press and hold the button on the bottom of the Bus Pirate.
    Plug in the USB cable.
    Release the button.

What happens next:
    A USB drive will appear on your computer, named RPI-RP2 (v5), RP2350 (v6), or BP__BOOT (v6), depending on your hardware version.
    Extract the correct firmware file from the downloaded .zip archive.
    Drag and drop the .uf2 firmware file into the USB drive.

Once the file is copied, the Bus Pirate will reset automatically and you’re ready to go!

Which firmware file?
    bus_pirate5_rev10.uf2 - Bus Pirate 5 revision 10 is by far the most common hardware. The bootloader drive will be named RPI-RP2
    bus_pirate6_rev2.uf2 - Bus Pirate 6 revision 2 with an RP2350 chip. The bootloader drive will be named RP2350 (v6), or BP__BOOT (v6)
